## 1. 天の川 ― 修正データと検証

### 何が間違っていたか(試作28) 【計算で確認済み】
- 旧 `mwSamples`(610点)は**赤緯 +27.5°〜+65° にしか点がない**。南天の天の川(いて座・さそり座・みなみじゅうじ座・ほ座・とも座など)が丸ごと無い。
- 銀緯(銀河面からの角度)で測ると、**123点が銀緯45°を超え、最大89.5°**(銀河北極のすぐそば)。天の川ではない場所に光が出る。
- 銀経 0〜30°、30〜60°、180〜360° の多くで、銀河面のそば(|b|≦3°)に点が1つも無い。
- 原因の推定: 等光度線を赤経・赤緯の平面で塗りつぶしたときの、**赤経の継ぎ目(0°/360°)と天の極まわりの扱い**の誤り。(推定。旧データの生成手順は未確認)

### 新データ 【実データ(d3-celestial 0.7.35 の mw.json)+計算】
- 差し替え先: 試作28の 423 行目 `const mwSamples=[…];` を `docs/mwfix/mw-samples.js` の中身に置き換える。
- 形式は旧と同じ `[0, 赤経J2000(度), 赤緯J2000(度), level]`。**level は 1〜5**(旧は 1〜2)。点数 **775**(旧 610)。

## 5. 彗星の尾(天頂ビュー) ― 修正方法

- 原因: p28 の尾の向き `dx=sin(Δ方位), dy=-sin(Δ高度)` は、**地平窓(東西南北)だけを想定した近似**。天頂ビュー(北が上・東が左の立体射影)では向きが合わない。
- 修正: `docs/handoff/patches/comet-tail.js` の `antiSolarTail(c.h, [sh.altitude, sh.azimuth], project, 48)` で置き換える。
  - 彗星と太陽の方向ベクトルから「太陽と反対向きの大円の接線」を出し、少し先の点を **そのビューの `project()` で投影**して画面上の向きを得る。どのビューでも自動で合う。太陽は地平線の下にあってよい。
  - 戻り値が `null` のとき(彗星が窓の端・太陽と同方向など)は、尾を描かず点だけにする。
- 検証: `tests/comet-tail.test.mjs` 5件合格(西の窓・天頂ビュー・大円上の独立計算との突き合わせ)。
- 注意: 天頂ビューは高度45°以上しか映らない(半径300px=高度45°)。彗星が低いときは天頂ビューには出ません(正常)。
- 尾の曲がり(塵の尾)や長さの変化は【演出】として入れていない。現状のまま。

## 6. 白夜地点の判定 ― 修正方法

### 現象 【計算で確認済み】
`daylight = (status==='sun-never-below')` は「その日、太陽が基準高度 −12° まで下がらない」=ゲームを休む日、という意味。ところが**描画も同じ旗で「昼の空」にしている**ため、太陽が深い薄明のときも昼になる。

23地点を2026年は3日おきに走査(2,806通り): `ok` 2,676 / `sun-never-below` 130 / `sun-never-above` 0 / `fallback-min` 0。
`sun-never-below` のうち、太陽の最低高度(【計算】):

| 地点・日 | 太陽の最低高度 | 実際の空 | p28 の描画 |
|---|---|---|---|
| ウシュアイア 2026-12-21 | −11.8° | 航海薄明の深い所(暗い青) | **昼** |
| イエローナイフ 2061-07-28 | −9.0° | 航海薄明 | **昼** |
| イエローナイフ 2026-06-21 | −4.1° | 市民薄明(まだ明るい) | 昼(ほぼ妥当) |
| トロムソ 2061-07-28 | −1.7° | 明るい薄暮 | 昼(妥当) |
| トロムソ 2026-06-21 | +3.1° | 白夜(太陽が出ている) | 昼(正しい) |
| 昭和基地 2026-12-21 | +2.4° | 白夜(太陽が出ている) | 昼(正しい) |

### 修正案(最小)
- `daylight`(=ゲーム休止の旗)は**そのまま**。
- 描画だけ、実際の太陽高度で決める:
  ```js
  // applySky() で、休止日なら基準時刻での太陽高度を持っておく
  restSunAlt = daylight ? r.reference.sunMinAltitude : null;   // 例: ウシュアイア12/21 → -11.8
  // draw() の bright 判定:
  const bright = elapsed>0 ? walkSun>=-6 : (daylight && restSunAlt>=-6);
  // 夜の濃さ(休止日で restSunAlt < -6 のとき): 空の散歩と同じ式
  night = daylight ? Math.max(0,Math.min(1,(-restSunAlt-6)/12)) : (今までの30秒の式);
  ```
  → ウシュアイア(−11.8°)は night≈0.48 の深い薄明、イエローナイフ(−9.0°)は ≈0.25。−6°以上は今までどおり昼。
- 休止日の表示文に太陽の最低高度を足す(例:「この日の太陽は最も低くても −11.8°」)。【計算】
- ゲームの扱い(休止のまま/薄明でも遊べるようにする)は**設計判断**で、今回は変えない。
- 極夜(`sun-never-above`)と `fallback-min`: 23地点・2026年の走査では出なかった。コード上の扱いは今のままでよい。
- 極(北極・南極)は地点に含まれていない → 【未確認】(含めるなら別途テストが必要)。
