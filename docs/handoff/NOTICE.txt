3. d3-celestial が挙げているデータの出典(d3-celestial の README の記述による)  【出典名は確認済み/各データの個別の利用条件は未確認】
----------------------------------------------------------------
 - 恒星: XHIP: An Extended Hipparcos Compilation (Anderson E., Francis C., 2012), VizieR V/137D
 - 星名・符号: HD-DM-GC-HR-HIP-Bayer-Flamsteed Cross Index (Kostjuk, 2002) ほか
 - 星名の翻訳(日本語を含む): Stellarium skycultures data
 - 星座線・星座名: IAU Constellation page、名前の位置と一部の線の修正は d3-celestial 作者による。
   他言語の星座名は Wikipedia から
 - 天の川の輪郭: Milky Way Outline Catalog (Jose R. Vieira)
 - 星雲・銀河(大小マゼラン雲、M31 など): dsos.bright.json(d3-celestial 作者の選定)
 d3-celestial の README は、これらの個別データに別のライセンスを示していません(リポジトリ全体が BSD-3-Clause)。
 ただし、元データ(XHIP/Hipparcos、Stellarium、Wikipedia、Vieira)側の利用条件を、
 こちらでは個別に確認していません。→ 【未確認】(下の「公開前の確認事項」)

4. このゲーム独自の計算・数値(ライセンス表示ではなく出典・性質の表示)
----------------------------------------------------------------
 - 流星群の活動期間・放射点: International Meteor Organization (IMO) Meteor Shower Calendar
   (Table 5 の値を目安として使用)https://www.imo.net/
 - ハレー彗星の等級パラメータ(M1=5.5, K1=8.0): NASA/JPL Small-Body Database
   軌道要素は二体問題の近似(惑星の引力による変化は無視)。位置・明るさは概算の【演出】
 - 観測地点の座標: Wikipedia、国土地理院(地理院地図の住所検索)など。利用条件の確認は【未確認】
 - 星の位置・月・惑星・太陽の計算: Astronomy Engine(上記)
 - 天の川・流星・願い事・オーロラ・彗星の尾・景色は【演出】で、実際の空を精密に再現するものではありません。
