# 今日の自分の一番星を探せ — Version 1.0

HTMLをブラウザで開いて遊べる星空シミュレーションです。GitHub Pagesでは index.html を配置してください。

23地点、恒星は6.0等まで。晴天固定。高精度な観測業務用ではありません。天の川・オーロラ・流星・ハレー彗星・景色は演出または概算です。
